# ADR-009 API Versioning
**Propuesta:** `/api/v1`, OpenAPI mantenido, modelo de errores, validación, paginación, correlation ID e idempotency key en operaciones de pago. **Contexto:** existen endpoints `/api/v1` y fuente frontend no entregada. **Consecuencia:** contratos pueden guiar Angular futuro sin diseñar UI; autorización por recurso es obligatoria.
