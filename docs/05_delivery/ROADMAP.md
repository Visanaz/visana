# Roadmap técnico de 24 semanas

| Fase / semanas | Resultado arquitectónico | Dependencias |
|---|---|---|
| Phase 0 Foundation, 1-3 | reproducibilidad, políticas, QA/observabilidad y ADR validados | recuperación de fuente, DG-14/15/16 según alcance |
| Phase 1 Core Platform, 4-7 | identidad/ownership, contratos de orders/payment y modelo de datos base | DG-14, GAP-019 |
| Phase 2 Network, 8-11 | genealogía, volumen y snapshots de calificación | DG-03, fuente/red aprobada |
| Phase 3 Financial, 12-17 | resolver de plan, Unilevel, ledger, settlement y payout | DG-01,02,04,05,07,08,09,10,11,12 |
| Phase 4 QA/Security, 18-20 | cobertura P0, contratos, E2E controlado y hardening | módulos anteriores |
| Phase 5 Migration/Go-live, 21-24 | staging, ensayos, conciliación, cutover y soporte | fuente/datos aprobados, DG y sign-off |

El orden permite avanzar en foundation, policies y contratos mientras reglas financieras permanezcan bloqueadas. No modifica el contrato comercial ni asigna horas.
