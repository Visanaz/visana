# Release Plan propuesto

| Release | Criterio de salida |
|---|---|
| R0 Foundation | build reproducible, ADRs, baseline de seguridad/QA y ambientes definidos |
| R1 Core | ownership, orders y pago verificable con contratos |
| R2 Network/Rewards | genealogía, volumen y calificación con snapshots trazables |
| R3 Finance | compensación/ledger/payout aprobados, auditables y con P0 test evidence |
| R4 Migration/Go-live | conciliación firmada, reversibilidad operativa y observabilidad |

Cada release requiere aprobación de gates aplicables, evidencias QA y ausencia de secretos en artefactos/logs. No es calendario comprometido.
