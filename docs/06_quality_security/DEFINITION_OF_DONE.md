# Definition of Done futura

Un feature no está terminado hasta que: regla/BR y DG trazados; código revisado; unit tests; integration cuando aplique; contrato API; migración revisada si existe; control de seguridad/ownership; logging y correlation; documentación; criterios de aceptación; manejo de reverso cuando afecte dinero; evidencia QA y aprobación de negocio para decisiones abiertas.

Esta DoD es propuesta de delivery; no afirma que el estado actual cumpla sus condiciones.
